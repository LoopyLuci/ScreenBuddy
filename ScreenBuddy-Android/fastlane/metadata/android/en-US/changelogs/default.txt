ScreenBuddy v0.7.0

* The AgenticBotPlatform integration, hardened and shipped: the desktop
  creature is a fleet backend, drives the fleet from inside the agent,
  and keeps persona, memory, events and the learning loop in sync with
  it.
* The MCP bridge reconnects and heartbeats, and the agent's tool surface
  is configurable so small local models see 11 clean schemas instead of
  72 mutation verbs.
* New Creature dashboard panel and a Creature Android control surface.
* Fixes the Android upgrade path from 0.6.2: the previous build shipped a
  stale version identity, so in-place upgrades were blocked.
